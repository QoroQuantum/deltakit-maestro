# Coherent noise on a repetition code

Coherent over-rotations on an MPS against their Pauli twirl on Maestro's stabilizer,
on a d=3 repetition code, both decoded with the twirl's detector error model. See
[Coherent noise](../guide/coherent_noise.md), and the
[notebook](coherent_noise_d3.ipynb) for the same comparison on the surface code,
with plots.

```bash
python examples/example_coherent_noise.py
```
